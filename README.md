# Arpha & Maryam — Invitation de mariage

Première version statique du site d'invitation.

## Publication simple avec GitHub + Vercel
1. Créez un dépôt GitHub nommé `arpha-maryam-wedding`.
2. Téléversez `index.html` à la racine du dépôt.
3. Dans Vercel, choisissez **Add New → Project**, importez le dépôt GitHub.
4. Pour ce site HTML statique, laissez les réglages de build par défaut si Vercel ne demande rien, puis cliquez sur **Deploy**.

## À personnaliser ensuite
- Remplacer les blocs illustratifs de la galerie par les vraies photos.
- Ajouter les adresses exactes et les liens Google Maps quand les lieux seront confirmés.
- Ajouter un contact et un formulaire RSVP si souhaité.
- Ajouter une musique avec un fichier audio dont vous avez les droits, avec un bouton lecture/pause.

Cette version ne contient pas encore de photos réelles, de musique ni de formulaire RSVP connecté.
